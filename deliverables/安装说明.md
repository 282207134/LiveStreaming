# Android 安装包

文件：`Utubee-1.0.0-android-arm64.apk`

适用于 Android 7.0（API 24）及以上的 arm64 Android 设备，以及本项目使用的 arm64 Android 模拟器。安装命令：

```bash
adb install -r deliverables/Utubee-1.0.0-android-arm64.apk
```

此包为 Release 构建，使用本机开发签名，供演示验收。商店发布需要替换正式 applicationId、配置发布签名并接入真实服务。

安装包的 SHA-256 校验值保存在同目录的 `SHA256SUMS`。

账号、视频与聊天使用本地演示逻辑，详见项目根目录的 README 和架构说明。首屏依次进入引导、Welcome；登录页默认填有演示信息，可以直接点击 Sign In 进入。
